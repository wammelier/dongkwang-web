# 동광교회 홈페이지 관리자 사용 설명서

홈페이지 글·주보·설교·배너를 바꾸는 방법입니다. 컴퓨터와 휴대폰 모두에서 쓸 수 있습니다.

> 이 설명서의 `<홈페이지 주소>`는 실제 주소가 정해지면 바꿔 적어 주세요.

---

## 1. 시작하기

### 로그인
1. 인터넷 창에서 `<홈페이지 주소>/admin` 으로 들어갑니다.
2. 초대받은 **이메일**과 **비밀번호**를 넣고 **로그인**을 누릅니다.
3. 왼쪽(휴대폰은 위쪽)에 메뉴가 보이면 성공입니다.

### 처음 초대받았을 때
- 메일함에 온 초대 메일의 링크를 누르면 **비밀번호 정하기** 화면이 열립니다.
- 다른 곳에서 쓰지 않는 **10자 이상**의 비밀번호를 정하고 **저장하고 시작하기**를 누릅니다.
- 초대 링크는 한 번만 쓸 수 있습니다. 만료되었다면 최고 관리자에게 다시 초대해 달라고 하세요.

### 비밀번호를 잊었을 때
로그인 화면의 **비밀번호를 잊으셨나요?** → 이메일 입력 → 메일의 링크를 **같은 컴퓨터·휴대폰**에서 열어 새 비밀번호를 정합니다.

### 내 역할 확인
| 역할 | 할 수 있는 일 |
| --- | --- |
| **콘텐츠 담당자** | 공지·행사·이야기, 주보, 설교, 절기 배너 |
| **최고 관리자** | 위의 모든 일 + 메인 구역, 교회 정보, 관리자 계정, 휴지통 완전 삭제 |

### 꼭 지켜 주세요
- 계정은 **사람마다 따로** 씁니다. 비밀번호를 다른 사람과 나누지 마세요.
- 공용 컴퓨터에서는 다 쓴 뒤 **로그아웃**을 누릅니다.
- **사람이 나온 사진은 본인(어린이는 보호자)의 공개 동의를 받은 뒤** 올립니다.

## 2. 글의 상태 — 먼저 알아 두기

모든 글(공지·주보·설교·특별 배너)은 아래 상태 중 하나입니다. 목록과 편집 화면 위쪽에 색깔 표시로 보입니다.

| 표시 | 뜻 | 홈페이지에 보이나요? |
| --- | --- | --- |
| 임시 저장 | 쓰는 중 | 아니요 (관리자에게만 보임) |
| 게시 중 | 공개됨 | **예** |
| 게시 예정 | 노출 시작 시각을 기다리는 중 | 그 시각부터 |
| 기간 종료 | 노출 종료 시각이 지남 | 아니요 |
| 게시 중단 | 일부러 내림 | 아니요 |
| 휴지통 | 버림 (복구 가능) | 아니요 |

- 저장 버튼은 화면 오른쪽(휴대폰은 화면 맨 아래)에 있습니다.
- 저장하지 않고 화면을 닫으려 하면 확인 창이 뜹니다.
- 저장에 실패하면 빨간 글씨로 이유가 나오고, 쓴 내용은 그대로 남아 있습니다.

## 3. 공지·행사·이야기 올리기

### 공지 하나 올리기 (가장 많이 쓰는 일)
1. 메뉴 **공지·행사·이야기** → 오른쪽 위 **+ 새 글 쓰기**
   (대시보드의 **빠른 글쓰기 → + 공지**를 눌러도 됩니다.)
2. **종류**에서 **공지**를 고릅니다.
3. **제목**을 씁니다. (필수)
4. **요약**에 한두 문장을 씁니다. 메인과 목록 카드에 보이는 글입니다.
5. **본문**을 씁니다. 줄을 바꾸면 홈페이지에서도 그대로 줄이 바뀝니다.
6. 위쪽 **미리보기** 탭을 눌러 홈페이지에서 어떻게 보일지 확인합니다.
7. **게시하기**를 누르면 홈페이지에 바로 올라갑니다.
   아직 다 못 썼다면 **임시 저장**을 누르세요.

### 행사 올리기
**종류**에서 **행사**를 고르면 **행사 정보** 칸이 더 나옵니다.
- **시작**(필수)·**종료** 날짜와 시각, **장소**, **대상**
- **신청 링크**: 구글 폼 같은 신청 주소. 비우면 "신청 방법은 본문을 확인해 주세요"로 보입니다.
- 종료 시각이 지나면 소식 페이지에서 자동으로 **지난 행사**로 옮겨집니다.

### 게시 설정 (오른쪽 칸)
- **중요 공지로 고정**: 메인과 목록 맨 앞에 "중요" 표시로 보입니다. 행사가 끝나면 꼭 풀어 주세요.
- **노출 시작**: 비우면 게시하는 즉시. 미래 시각을 넣으면 그때부터 보입니다(게시 예정).
- **노출 종료**: 비우면 계속 보입니다. 넣으면 그 시각에 저절로 내려갑니다.
- 시각은 모두 **한국 시간**입니다. 시작·종료는 최대 1시간 늦게 반영될 수 있습니다.

### 사진·첨부파일 붙이기
1. 글을 먼저 **임시 저장**하거나 **게시**합니다. (저장한 글에만 파일을 붙일 수 있습니다.)
2. 아래 **사진·첨부파일** 칸에서
   - **사진 올리기**: JPG·PNG·WEBP, 한 장에 10MB 이하
   - **파일 붙이기**: PDF·한글·워드·엑셀·파워포인트, 20MB 이하
3. 사진은 **공개 동의 확인**에 체크해야 홈페이지에 보입니다. 사람이 없는 풍경 사진도 확인 후 체크하세요.
4. 파일은 올리는 즉시 저장됩니다. **빼기**를 누르면 바로 지워집니다.

### 고치기·내리기·지우기
- 목록에서 제목을 누르면 고칠 수 있습니다. 게시 중인 글은 **저장**을 누르면 바로 바뀝니다.
- **게시 중단**: 홈페이지에서 내립니다. 나중에 **다시 게시**할 수 있습니다.
- **휴지통으로 옮기기**(편집 화면 아래쪽): 목록의 **휴지통** 탭에서 **복구**할 수 있습니다.
- **완전 삭제**는 최고 관리자만, 휴지통에서만 할 수 있고 되돌릴 수 없습니다.

### 글 찾기
목록 위의 **상태 탭**(전체·임시 저장·게시·게시 중단·휴지통), **제목 검색**, **종류** 선택을 쓰세요.

## 4. 주보 올리기

1. 메뉴 **주보** → **+ 주보 올리기**
2. **날짜**는 다가오는 주일로 미리 채워져 있습니다. 다르면 바꿉니다.
3. **제목**은 날짜에 맞춰 "11월 둘째 주 주보"처럼 자동으로 들어갑니다. 필요하면 고칩니다.
4. **설명**(선택): 목록에 함께 보이는 한 줄입니다.
5. **PDF 또는 사진 올리기**를 눌러 주보 파일을 고릅니다. (20MB 이하)
   올라가면 화면에서 바로 미리 볼 수 있습니다.
6. **게시하기**를 누르면 메인의 **이번 주 주보**가 이 주보로 바뀝니다.

- 같은 날짜의 주보는 하나만 올릴 수 있습니다. "이미 있습니다"라고 나오면 목록에서 그 주보를 열어 파일을 바꾸세요.
- 파일을 잘못 올렸다면 **다른 파일로 바꾸기** → **저장**. 이전 파일은 자동으로 지워집니다.
- 파일이 너무 크면 PDF를 저장할 때 "용량 줄이기"(인쇄 품질 낮추기)를 쓰세요.

---

## 5. 설교 등록

1. 메뉴 **설교** → **+ 설교 등록**
2. **제목**, **설교 날짜**, **본문**(예: 요한일서 4:7–12)을 씁니다.
3. **설교자**: 이름만 쓰면 "목사"가 붙습니다. 다른 직함은 함께 써 주세요(예: 김철수 선교사).
4. **영상 링크**: 유튜브 영상의 **공유** 버튼으로 받은 주소를 붙여 넣습니다.
5. **요약**: 메인 **최근 말씀**과 설교 상세에 보입니다.
6. 아래 **미리보기**를 확인하고 **게시하기**를 누릅니다. 가장 최근 설교가 메인에 나옵니다.

## 6. 절기 배너 (메인 맨 위)

메인 맨 위의 큰 문구입니다. **처음에는 절기가 바뀌어도 지금 보이는 문구(연중)가 그대로 유지됩니다.**
절기에 맞춰 바꾸고 싶은 절기만 **‘적용’ 스위치를 켜세요.** 켠 절기는 **해마다 그 날짜에** 저절로 바뀝니다. 날짜를 매년 넣을 필요가 없습니다.

메뉴 **절기 배너**에서:
- **지금** 보이는 배너와 **다음 전환** 시각을 확인합니다. 적용한 절기가 없으면 "기본(연중) 배너 유지 중"이라고 나옵니다.
- **날짜로 미리보기**: 날짜를 고르면 그날 보일 배너를 PC·휴대폰 모양으로 볼 수 있습니다. 아무것도 바뀌지 않습니다.

### 절기 적용하기
1. **○○년 절기 배너** 목록에서 바꾸고 싶은 절기(예: 대림절)의 **스위치를 켭니다.** ("적용 안 함" → "적용 중")
2. 그 절기의 날짜가 되면 배너가 바뀌고, 날짜가 지나면 다시 연중 배너로 돌아옵니다. **다음 해에도 같은 날짜에** 반복됩니다.
3. 끄고 싶으면 스위치를 다시 끕니다. **켜지 않은(끈) 절기의 기간에는 연중 배너를 그대로 유지합니다.**
4. 위쪽 **날짜로 미리보기**에서 그 절기의 날짜를 골라 확인해 보세요.

- **연중**은 기본 배너라 스위치가 없고 항상 보입니다.
- **추수감사절**도 같은 방식입니다. 켜면 11월 셋째 주일 14일 전부터 그 주일까지 보입니다.

### 절기 문구 고치기
1. 절기 옆 **문구 고치기**
2. **헤드라인**(두 줄까지)과 **짧은 설명**을 고치고 **저장**
3. 원래대로 돌리려면 **기본 문구로 되돌리기**

- **문구를 고쳐도 ‘적용’ 여부는 바뀌지 않습니다.** 적용하지 않은 절기의 문구는 저장만 해 두었다가, 스위치를 켜면 그때부터 나옵니다.

### 특별 배너 (행사·창립기념일 등)
1. **+ 특별 배너 만들기**
2. **작은 제목**, **헤드라인**, **짧은 설명**을 씁니다.
3. 행사 버튼이 필요하면 **버튼 글자**(예: 행사 안내)와 **버튼 주소**를 함께 씁니다.
   사이트 안의 글이면 그 글 주소의 `/news/...` 부분을 넣으면 됩니다.
4. **보이는 기간**: **끝** 시각은 꼭 넣어야 합니다. 끝나면 그때의 배너(적용한 절기가 있으면 그 절기, 없으면 연중)로 저절로 돌아갑니다.
5. 아래 안내를 확인합니다.
   - 주황색: **적용해 둔** 부활절·성탄절 같은 중요한 절기를 가립니다. 정말 그 기간이 맞는지 확인하세요.
   - 빨간색: 이미 게시 중인 다른 특별 배너와 기간이 겹칩니다. 기간을 바꾸거나 먼저 그 배너를 게시 중단하세요.
6. **미리보기**를 확인하고 **게시하기**

- 헤드라인에는 **확정된** 날짜·시간만 넣어 주세요.

## 7. 메인 구역 (최고 관리자)

메뉴 **메인 구역**에서 메인 페이지 아래쪽 구역을 정리합니다. 맨 위 배너와 예배·주소 안내는 항상 고정입니다.
- **켜짐/꺼짐** 스위치로 구역을 보이거나 숨깁니다.
- **↑ ↓** 버튼으로 순서를 바꿉니다. 오른쪽 **미리보기**로 배치를 확인하고 **저장**합니다.
- 구역 이름 아래 **문구 고치기**로 구역 제목과 소개 문구를 바꿀 수 있습니다. 비우면 원래 문구로 돌아갑니다.

## 8. 교회 정보 (최고 관리자)

메뉴 **교회 정보**는 탭마다 따로 **저장**합니다.

| 탭 | 내용 | 홈페이지 어디에 |
| --- | --- | --- |
| 기본 정보 | 이름, 교단, 주소, 전화, 사무실 시간, 지도 링크, 공식 채널 | 맨 아래 정보, 오시는 길 |
| 방문 안내 | 주차, 대중교통, 이동 편의, 처음 오신 분 단계 | 메인, 방문 안내 |
| 교회 소개 | 소개문, 신앙과 방향, 담임목사 인사, 섬기는 사람들, 연혁 | 교회 소개 |
| 예배 시간 | 예배 이름·요일·시각·장소, 대표 예배 | 메인 예배 안내, 예배 안내 |
| 공동체 | 모임 이름·대상·시간·장소·참여 방법 | 메인, 다음세대·공동체 |
| 자주 묻는 질문 | 질문과 답변 | 방문 안내 |

- 목록 항목은 **+ 추가**, **↑ ↓**(순서), **×**(빼기)로 정리합니다.
- **대표 예배**는 하나만 정할 수 있습니다. 메인 맨 위 예배 안내에 크게 나옵니다.
- 잠시 쉬는 예배·모임은 지우지 말고 **홈페이지에 보이기**를 끄세요.
- **지도 링크**: 네이버·카카오 지도에서 교회를 찾은 뒤 **공유 → 링크 복사**한 주소를 넣습니다.

## 9. 관리자 계정 (최고 관리자)

### 새 관리자 초대
1. 메뉴 **관리자 계정** → **새 관리자 초대**
2. 이름, 이메일, 역할(보통 **콘텐츠 담당자**)을 고르고 **초대 메일 보내기**를 누릅니다.
3. 상대방이 초대 메일에서 비밀번호를 정하면 로그인할 수 있습니다.

### 담당자가 바뀌었을 때
이전 사람의 계정을 **비활성화**합니다. 그 즉시 로그인과 수정이 막힙니다.
최고 관리자는 항상 한 명 이상 있어야 하므로, 마지막 최고 관리자는 비활성화할 수 없습니다.

## 10. 문제가 생겼을 때

| 상황 | 해결 |
| --- | --- |
| 게시했는데 홈페이지에 안 보여요 | 상태가 **게시 중**인지, **노출 시작**이 미래로 되어 있지 않은지 확인하세요. 브라우저를 새로고침해 보세요. |
| 사진이 홈페이지에 안 보여요 | 사진의 **공개 동의 확인**에 체크했는지 확인하세요. |
| 파일이 안 올라가요 | 형식(PDF·사진 등)과 크기(주보 20MB, 사진 10MB)를 확인하세요. 오래 켜 두었다면 다시 로그인하세요. |
| "로그인이 풀렸습니다"가 나와요 | 다시 로그인한 뒤 저장하세요. 쓰던 내용은 미리 복사해 두면 안전합니다. |
| 링크가 만료되었다고 나와요 | 초대·비밀번호 메일 링크는 한 번만 쓸 수 있습니다. 비밀번호 찾기로 새 링크를 받으세요. |
| 실수로 지웠어요 | 목록의 **휴지통** 탭에서 **복구**하세요. 완전 삭제한 것은 되돌릴 수 없습니다. |
| 메뉴가 안 보여요 | 메인 구역·교회 정보·관리자 계정은 최고 관리자에게만 보입니다. |

해결되지 않으면 화면에 나온 문구(오류 번호 포함)를 적어 홈페이지 관리 담당자에게 알려 주세요.
모든 중요한 수정은 누가 언제 무엇을 바꿨는지 기록에 남습니다.
