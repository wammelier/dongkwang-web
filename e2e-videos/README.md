# E2E 테스트 영상

홈페이지 전체를 실제 크롬으로 둘러본 화면 녹화입니다. 화면 아래 자막이 지금 확인하는 내용을 알려 주고, 빨간 점이 마우스 위치입니다.

촬영일: 2026-11-07 · 촬영 환경: 이 PC의 개발 서버(`localhost:3000`) + 실제 Supabase 데이터

| 파일 | 길이 | 크기 | 내용 |
| --- | --- | --- | --- |
| `01-웹사이트-PC.webm` | 56초 | 1280×720 | 방문자 화면 전체 (PC) |
| `02-웹사이트-모바일.webm` | 34초 | 374×812 | 방문자 화면 전체 (휴대폰) |
| `03-어드민-PC.webm` | 2분 22초 | 1280×720 | 관리자 화면 전체 (PC) |

## 보는 법

`.webm` 파일을 **크롬이나 엣지 창에 끌어다 놓으면** 바로 재생됩니다. (더블클릭해도 열리지만, Windows 기본 앱은 컴퓨터에 따라 안 열릴 수 있습니다.)

## 영상마다 담긴 내용

### 01 · 02 웹사이트 (로그인 없이 방문자가 보는 화면)

- 메인: 절기 배너, 예배·주소·주차·주보 안내, 처음 오신 분, 교회 소개, 최근 말씀, 소식, 공동체
- 상단 메뉴로 교회 소개, 예배·말씀, 다음세대·공동체, 교회 소식 이동
- 설교 목록 → 상세, 소식 탭(공지·행사·교회 이야기) → 상세, 주보 목록
- 처음 오셨나요: 방문 안내와 자주 묻는 질문 펼치기
- 없는 주소로 갔을 때의 안내 화면 (PC)
- 모바일: 메뉴가 화면 위에 겹쳐 열리는 모습

### 03 어드민 (로그인한 최고 관리자)

1. 대시보드
2. 공지 쓰기 → 미리보기 → **임시 저장** → 방문자에게는 안 열림(없는 페이지)
3. 사진 올리기 → **공개 동의 확인** → 게시 → 방문자 화면에 글과 사진 표시
4. 휴지통 → 복구 → 완전 삭제
5. 행사 입력 칸(일시·장소·신청 링크)
6. 주보 PDF 올리기 → 미리보기 → 게시 → 방문자 주보 목록 반영
7. 설교 등록 → 게시 → 방문자 설교 목록 반영
8. 절기 배너: **켜지 않으면 연중 유지**, 대림절을 켜면 12월 1일이 대림절로 바뀜 → 다시 끔
9. 특별 배너 만들기(임시 저장까지), PC/휴대폰 미리보기
10. 메인 구역, 교회 정보 6개 탭, 관리자 계정 (보기만)
11. 로그인 상태가 없으면 관리자 화면이 로그인 화면으로 연결됨

## 촬영하면서 지킨 안전장치 (운영 데이터 보호)

- 만든 글·주보·설교·배너는 모두 제목이 `[E2E]`로 시작하고, 촬영이 끝나면 **자동으로 지워집니다.** (올린 사진·PDF 파일도 저장소에서 함께 삭제)
- 주보·설교는 **2000년 날짜**로 올려서 실제 메인의 "이번 주 주보·최근 말씀"이 바뀌지 않습니다.
- 교회 정보·메인 구역·관리자 계정은 **보기만** 하고 저장하지 않았습니다.
- 절기 스위치는 켰다가 **반드시 다시 끄도록** 했습니다. (촬영 뒤 전부 꺼진 것을 확인)
- 실제 **로그아웃 버튼은 누르지 않았습니다.** Supabase 로그아웃은 같은 계정의 다른 기기·창 로그인까지 모두 끊기 때문입니다. 대신 로그인 쿠키를 지운 상태로 접근이 막히는 것만 보여 줍니다. (실제 로그아웃은 `e2e/login.spec.ts`가 전용 시험 계정으로 검증)

## 알아 두실 점

- **어드민 영상에는 로그인한 관리자 이메일이 화면에 보입니다**(왼쪽 아래, 관리자 계정 화면). 영상을 다른 사람에게 보내기 전에 확인하세요.
- **로그인 입력 장면은 없습니다.** 비밀번호는 자동화 도구가 입력하지 않고, 사람이 직접 로그인해 저장한 상태로 촬영했습니다.
- 화면의 `[교회 주소]` 같은 대괄호 문구는 **실제 교회 정보가 아직 입력되지 않아서** 남아 있는 것입니다. 정보를 입력한 뒤 다시 촬영하면 달라집니다.
- 영상 파일은 용량이 커서(합계 약 27MB) 저장소에 올릴지는 따로 정하세요.

## 다시 촬영하기

```bash
npm run e2e:login   # 크롬 창이 열리면 직접 로그인 (어드민 영상만 필요)
npm run e2e:video   # 세 영상을 모두 다시 촬영
```

- 개발 서버(`npm run dev`)가 켜져 있으면 그대로 쓰고, 없으면 자동으로 띄웁니다.
- 어드민만 다시 찍으려면 `npx playwright test -c playwright.tour.config.ts admin`, 웹사이트만은 `... public`.
- 로그인 상태 파일(`e2e/.auth/admin.json`)은 git에 올라가지 않습니다. 일정 시간이 지나면 만료되니, 실패하면 `e2e:login`을 다시 실행하세요.
- 촬영 스크립트: `e2e/tour/public.spec.ts`, `e2e/tour/admin.spec.ts`, 도구: `e2e/tour/helpers.ts`
